# Дизайн eViSTool 1.0 — лесная тема, вариант «В»

Общая договорённость по виду окна к выпуску 1.0. Эскиз, по которому выбран вариант: экран «Мои моды» в HTML
(варианты «Сейчас», А, Б, В); выбран **В «лесной»**. Палитра остаётся лесной: меняются глубина слоёв, отклик на
действия и пара живых деталей. Значения ниже обязательны: несколько людей и агентов должны получить один и тот же вид.

Главная мысль: интерфейс «плоский», потому что слои почти одной светлоты, ничего не двигается, а наведение делает
элемент тусклее. Чиним это светлотой, кромками, короткими переходами и проседанием кнопок — без свечений, без
стекла, без долгих анимаций.

## 2. Глубина

- **Кромка.** У карточек (`Border.card`), кнопок, плашек и выбранного пункта меню — светлая линия сверху:
  `BoxShadow="inset 0 1 0 0 {Forest.Edge}"`.
- **Подъём карточки** (страницы, диалоги): кромка плюс тень `0 1 0 0 #61000000, 0 10 24 -14 #61000000`. Тень
  тёмная и короткая; цветных свечений нет.
- **Диалоги** (окна поверх): фон Raised, рамка LineStrong, скругление 12, кромка и тень `0 24 48 -16 #99000000`.
- Скругления: карточки 10, кнопки и поля 7, чипы 6, диалоги 12.
- Карточка в карточке — нет. Внутренний блок — фон на ступень светлее, без своей рамки.

## 3. Движение

Длительности (из канона hallmark):

| Что | Длительность | Кривая |
|---|---|---|
| нажатие (проседание), щелчок переключателя | 60–100 мс | торможение |
| наведение, смена цвета, ручка переключателя, подчёркивание вкладки | 180 мс | торможение |
| появление страницы, содержимого вкладки, диалога | 250 мс | торможение |
| уход (закрытие диалога и т. п.) | ~70 % от появления | разгон |
| фокус клавиатуры | 0 мс — кольцо появляется сразу | — |

Кривая «торможение» — `0.2, 0.7, 0.2, 1` (быстрый старт, мягкая остановка); «разгон» — `0.5, 0, 0.75, 0`. Отскоков и
пружин нет. Анимируются только цвет, прозрачность и `RenderTransform`, но не размеры и не отступы: раскладку на каждом
кадре не пересчитываем.

- **Кнопки.** Наведение — фон Raised и рамка LineStrong, плавно. Нажатие — `scale(0.985) translateY(1px)` за 60 мс,
  отпускание — 100 мс; тень и кромка на время нажатия пропадают. Выключенная кнопка — без фона и рамки, текст Faint
  (не полупрозрачная копия обычной).
- **Главная кнопка** (`.primary`) — выпуклая: вертикальный градиент AccentTop → Accent, кромка `inset 0 1 0 0
  #59FFFFFF`, тень `0 1 0 0 #61000000`. Наведение — AccentHover, нажатие — AccentPressed и проседание.
- **Наведение делает ярче, а не тусклее.** Никаких `Opacity 0.8` на наведении: ссылка — AccentHover, счётчик и
  вкладка — Text, дорожка переключателя — рамка LineStrong.
- **Фокус клавиатуры** — кольцо 2 px Accent с отступом 2 px вокруг элемента (отдельная рамка в шаблоне), без анимации.
- **Переключатель** (`Forest.Switch`) — ручка едет через `RenderTransform` (translateX) за 180 мс, дорожка плавно меняет
  цвет. Не переключать выравнивание: его не анимировать.
- **Вкладки** (`Forest.TabHeader`, `Forest.StatTab`) — подчёркивание выбранной плавно появляется (масштаб по
  горизонтали от центра и прозрачность, 180 мс).
- **Полоса прогресса** — у неопределённой (`IsIndeterminate`) бегущий отрезок 30 % ширины, 1 с, по кругу.
- **Смена страницы** (пункт меню) и **смена вкладки внутри страницы** — новое содержимое проявляется: прозрачность
  0 → 1 и сдвиг на 6 px снизу, 250 мс. Сдвига вбок нет.
- **«Дышащая» точка** — только у состояния «сервер работает»: мягкое кольцо вокруг зелёной точки раз в 2,6 с. Больше
  ничего само по себе не двигается.
- **Мерцающие заглушки** — пока идёт проверка обновлений, вместо статусов модов полоски-заглушки с бегущим бликом.
- Не больше трёх видов движения на экране одновременно. Если движение ничего не сообщает — его нет.
- Если в системе выключены анимации (Windows: «Показывать анимацию в Windows», GNOME: enable-animations) — переходы
  мгновенные, «дыхание» и блик выключены.

## 4. Типографика

Шрифт прежний — Noto Sans, моноширинный — Cascadia Mono. Ступени крупнее, их меньше:
заголовок страницы 28 (SemiBold), заголовок окна-диалога 20, заголовок карточки 16 (SemiBold), основной текст 13,
подписи 12, мелкие пометки 11. Заголовки всегда прямые, курсива в заголовках нет.

## 5. Фон из игры

Под боковой панелью — размытая заставка главного меню Vintage Story.

- **Откуда.** Только из папки установленной игры, в программу картинки не вшиваются (это арт Anego Studios; кроме
  того, игроки подменяют заставки своими — их и покажем). Папки ищутся так же, как для значка игры
  (`MainViewModel.IconSearchDirs`): игра активного профиля, игры остальных профилей, найденная игра. Картинки:
  `assets/game/textures/gui/backgrounds/mainmenu1.png` … `mainmenu7.png`, праздничные `mainmenu-halloween.png`,
  `mainmenu-xmas.png`. Первая папка, где нужный файл есть, — та и берётся.
- **Какая.** Хэллоуин — с 28 октября по 3 ноября включительно, Рождество — с 22 по 28 декабря включительно (местная
  дата); в эти дни праздничная. В остальные — картинка недели: номер недели N = число дней от фиксированного понедельника
  ÷ 7; картинка = `mainmenu{(N·3) mod 7 + 1}`. Соседние недели всегда разные, за 7 недель проходят все 7. Ничего не
  хранится: в любой день и после любого перезапуска неделя даёт одну и ту же. Нужной нет — следующая по кругу из
  существующих; праздничной нет — картинка недели.
- **Как рисуется.** На всё окно (обе колонки), `Stretch="UniformToFill"` — без полос и без искажения, лишнее обрезается.
  Видна только под боковой панелью: правая часть окна закрыта непрозрачным фоном Base. Над картинкой в боковой панели —
  вуаль Forest.SideVeil (75 %); выбранный пункт меню, наведение и карточка профиля — «вуалевые» токены из раздела 1.
- **Размытие — один раз, не на каждом кадре.** Никакого `BlurEffect` на элементе. При загрузке: декодировать сразу в
  уменьшенный размер (около 480 px по ширине), размыть один раз (края — повтор крайних пикселей, без тёмной каймы), для
  праздничных с прозрачностью — подложить цвет Side, результат держать в памяти как обычный Bitmap. Сила размытия —
  как в эскизе: 5 экранных пикселей при окне около 1400 px, то есть радиус около 1,7 px на картинке 480 px (уменьшение
  само смягчает — подобрать на глаз, чтобы картинка читалась как размытая, а не мыльная).
- **Когда заново.** При запуске, при смене активного профиля или его папки игры, раз в час (вдруг наступила новая неделя
  или праздник) и при включении галочки. Перечитывать файл, только если выбор поменялся. Кэш — только в памяти, на время
  работы: подменённая игроком картинка видна со следующего запуска.
- **Заглушка.** Галочка выключена, игры нет нигде, файла нет, файл не читается — под боковой панелью цвет Side и
  спокойный узор «горизонтали»: несколько волнистых линий цвета Accent с прозрачностью 7 % (векторный узор, не
  картинка). Линии медленно плывут, но почти бесплатно: сдвиг на 1 px раз в 150–200 мс по таймеру (5–7 перерисовок
  в секунду, а не 60), перерисовывается только боковая панель; движение стоит, когда окно свёрнуто, неактивно или в
  системе выключены анимации.
- **Галочка.** «Настройки» → «Вид» → «Фон из игры» (`MainViewModel.GameBackground`, `AppSettings.GameBackground`,
  по умолчанию включено; тексты `settings.gameBackground`, `settings.gameBackgroundHint`).

## 6. Страницы «Профили» и «Настройки»

Боковое меню: Мои моды · Каталог модов · Настройки модов · Сервер · **Профили** · **Настройки** · О программе.
Подпись капсом «РАБОЧЕЕ ПРОСТРАНСТВО» над меню и такое же начало строки-пути вверху убираются: другого
пространства в программе нет.

- **«Профили»** — всё, что относится к конкретному профилю: список профилей и действия с ними («+ Клиент»,
  «+ Сервер», «Клонировать…», «Уборка диска…», «Удалить профиль»); карточка выбранного профиля — название, тип,
  подключение (код агента, сервер у хостера и напоминание «останови сервер»), папки игры и данных, версия игры, файл
  настроек, папки модов, сервер по умолчанию для «Играть», связанные профили; копии миров этого профиля.
- **«Настройки»** — общее для всей программы, смысловыми блоками:
  - **Вид** — язык, фон из игры, системная рамка окна (только Linux, как сейчас);
  - **Обновления** — проверять обновления eViSTool автоматически, предлагать нестабильные версии модов;
  - **Моды** — «Установить также в» без вопроса, копии миров перед изменением модов;
  - **Оповещения** — каналы (Telegram, Discord, ntfy, webhook);
  - **Данные программы** — где лежат.
- Переходы «открыть настройки профиля» из других разделов (например, «Мои моды» и «Сервер» у хостера) ведут на
  «Профили».

## 7. Живые детали

- Иконка мода в строке «Моих модов» (и везде, где сейчас квадрат с буквами) — по цепочке:
  1. `modicon.png` из файла мода (zip или папка) — квадратная иконка, которую автор делает для списка модов в игре;
     с диска, без сети;
  2. логотип мода с ModDB — если в файле иконки нет, и для удалённого сервера и сервера у хостера, где файла под рукой
     нет (адрес логотипа — из каталога; стандартную картинку ModDB «mod-default» не берём);
  3. цветные инициалы.
  Декодировать сразу в маленький размер (около 64 px), кэш в памяти, загрузка в фоне только для видимых строк, файл
  мода открывать один раз. Квадрат: картинка по центру, лишнее обрезается (UniformToFill), скругление как у плитки.
- Инициалы модов без иконки — фон с оттенком по modid (детерминированный хеш → оттенок, светлота и насыщенность
  постоянные, текст светлый того же оттенка).
- Пустая правая панель «Моих модов» — не «Выбери мод в таблице», а сводка профиля: сколько модов включено, проблемы,
  когда проверялись обновления, кнопка «Проверить обновления».
- У выбранной строки таблицы — песочная метка 2 px слева.
- Пустые состояния «Сервера»: у остановленного сервера в консоли — «Сервер остановлен» и кнопка «Запустить»; плитки
  до запуска приглушены, без прочерков.
- «Дышащая» точка у карточки профиля внизу боковой панели — только когда сервер профиля работает.

## 8. Проверка

- Сборка без предупреждений, все три набора тестов зелёные.
- Снимки (`build/snapshot.ps1`) всех экранов до и после: всё, что поменялось, — поменялось намеренно.
- Проверка вживую на Windows и на Linux (ВМ с GNOME под Xwayland): плавность переходов, читаемость меню над фоном,
  растяжение окна без полос.
