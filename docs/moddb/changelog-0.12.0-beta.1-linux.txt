eViSTool 0.12.0-beta.1 for Linux: mods on a server rented from a host (G-Portal and others) over FTP.

This is a beta, checked on a real G-Portal server. Other hosts may lay out their files differently: if something goes wrong, please write in the comments which host you use.

- New profile → "Hosted server" in the window: FTP address, port, login and password from the host's panel, then Check connection. eViSTool finds serverconfig.json, the mods folders and the game version by itself.
- Mod list, update checks, install, update, rollback, turning mods off and on, deleting. Turning a mod off changes only WorldConfig.DisabledMods in serverconfig.json. Before every replacement or deletion the old version is saved on this computer.
- The host's own mods (gportal_mods) are shown read-only. Before the first change eViSTool reminds you to stop the server in the host's panel.
- The password is stored encrypted with a key only your user can read.
- Not yet: SFTP and mod settings over FTP. Starting the server, the console and players stay in the host's panel.
- "In catalog" no longer opens a random mod for a mod without a modid.

eViSTool 0.12.0-beta.1 для Linux: моды на сервере у хостера (G-Portal и другие) по FTP.

Это бета, проверена на настоящем сервере G-Portal. У других хостеров файлы могут лежать иначе: если что-то пошло не так, напиши в комментариях, какой у тебя хостер.

- «Новый профиль» → «Сервер у хостера» в окне: адрес FTP, порт, логин и пароль из панели хостера, потом «Проверить подключение». eViSTool сам найдёт serverconfig.json, папки модов и версию игры.
- Список модов, проверка обновлений, установка, обновление, откат, выключение и удаление. При выключении мода в serverconfig.json меняется только WorldConfig.DisabledMods. Перед каждой заменой и удалением старая версия сохраняется на этом компьютере.
- Моды самого хостера (gportal_mods) видны, но менять их нельзя. Перед первым изменением eViSTool напомнит остановить сервер в панели хостера.
- Пароль хранится зашифрованным ключом, который может прочитать только твой пользователь.
- Пока нет: SFTP и настроек модов по FTP. Запуск сервера, консоль и игроки остаются в панели хостера.
- «В каталоге» больше не открывает случайный мод для мода без modid.
