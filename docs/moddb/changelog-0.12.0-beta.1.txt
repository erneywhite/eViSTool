eViSTool 0.12.0-beta.1: mods on a server rented from a host (G-Portal and others) over FTP.

This is a beta. It was checked on a real G-Portal server, but other hosts may lay out their files differently. If something goes wrong, please write in the comments which host you use.

New
- New profile → "Hosted server": enter the FTP address, port, login and password from the host's panel and press Check connection. eViSTool finds serverconfig.json, the mods folders and the game version by itself.
- The mod list, update checks, install, update, rollback to another version, turning a mod off and on, and deleting work the same as for a local server. Turning a mod off changes only WorldConfig.DisabledMods in serverconfig.json, everything else in the file stays as the host's panel wrote it.
- Before every replacement or deletion the old version is saved on this computer, so a mod can be brought back from History.
- The host's own mods (G-Portal's gportal_mods folder) are shown, but cannot be changed.
- Before the first change eViSTool reminds you to stop the server in the host's panel; the answer is remembered for 10 minutes. The reminder can be turned off in the profile settings.
- The password is stored encrypted for the current Windows user and is never shown.
- Starting the server, the console, players and the schedule stay in the host's panel.

Not yet: SFTP and mod settings (ModConfig) over FTP.

Fixes
- "In catalog" no longer opens a random mod for a mod without a modid.

eViSTool 0.12.0-beta.1: моды на сервере у хостера (G-Portal и другие) по FTP.

Это бета. Проверена на настоящем сервере G-Portal, но у других хостеров файлы могут лежать иначе. Если что-то пошло не так, напиши в комментариях, какой у тебя хостер.

Новое
- «Новый профиль» → «Сервер у хостера»: введи адрес FTP, порт, логин и пароль из панели хостера и нажми «Проверить подключение». eViSTool сам найдёт serverconfig.json, папки модов и версию игры.
- Список модов, проверка обновлений, установка, обновление, откат на другую версию, выключение и удаление работают так же, как у своего сервера. При выключении мода в serverconfig.json меняется только WorldConfig.DisabledMods, остальное остаётся как записала панель хостера.
- Перед каждой заменой и удалением старая версия сохраняется на этом компьютере, и мод можно вернуть из «Истории».
- Моды самого хостера (папка gportal_mods у G-Portal) видны в списке, но менять их нельзя.
- Перед первым изменением eViSTool напомнит остановить сервер в панели хостера, ответ помнится 10 минут. Напоминание отключается в настройках профиля.
- Пароль хранится зашифрованным для текущего пользователя Windows и нигде не показывается.
- Запуск сервера, консоль, игроки и расписание остаются в панели хостера.

Пока нет: SFTP и настроек модов (ModConfig) по FTP.

Исправления
- «В каталоге» больше не открывает случайный мод для мода без modid.
