I play Vintage Story with a lot of mods and run a small server for friends, and I got tired of checking every mod for updates by hand, copying zips around and connecting to the server just to restart it. So I made eViSTool. It's one window where you can keep your mods up to date, grab new ones from the ModDB and look after your dedicated server.

It's free, open source and portable: unzip it anywhere and run it. Nothing gets installed, nothing runs in the background when you don't need it.

Your mods

Hit Check and you'll see which mods have updates. Update one or all of them in one go. If an update breaks something, roll back to the version you had before — eViSTool keeps the old files around for exactly that. You can pin a mod to its current version or skip one particular release you don't want.

It also warns you about the usual headaches before they bite: a missing or outdated dependency (one button fixes it), a duplicate mod, a version made for another game branch, a mod that needs a newer game than you have. And if you keep a separate mod set for a server, it tells you which mods are client-only and don't belong there.

Want to share your setup with a friend? Save it as a modpack and send them one file.

Before mods change, eViSTool quietly copies the single-player worlds you played since the last copy. If an update breaks a world, put the copy back with one button.

Mod settings without editing JSON by hand

The Mod settings tab lists the config files of your mods and opens them as a form: switches, number fields, lists. A typo can't break the file, every save keeps the previous version (one button brings it back), and Reset to defaults lets the mod create a fresh config. It works for your server on another PC too.

The whole ModDB inside the app

Search, filter by tag, side and game version, sort by what's trending. Every mod shows its screenshots, description and all releases, and installs with one click — dependencies included.

Profiles

Keep several setups side by side: your main game, a separate mod set for a particular server, a test profile. Each has its own mods, settings and worlds, and the Play button starts the game with the one you picked. eViSTool also notices when that game is already running, so you won't start the same setup twice.

Many mods have to be on both the server and your client. When you install one of those, eViSTool offers to put it into your other profiles as well, and each profile gets the right version for its game. Link the profiles once and it happens without asking.

The arrow next to Play lets you start the game and join a server right away: your own servers, the game's favorites, or any server from the public list — with search, filters and a look at its mods before you join. Pin one and Play takes you straight there.

When something breaks

A crash to desktop, a world that throws you back to the main menu, a server that goes down in the middle of the night: eViSTool reads the logs and tells you which mod is most likely to blame. You don't have to scroll through a stack trace or turn mods off one by one. Disable the mod right from that window, or copy the report and send it to the mod's author. For servers, the alert reaches you whichever profile you have open, even when the server is on another PC.

Some mods never crash anything, they just keep spamming errors while the game swallows them, and the log swells and the game stutters. eViSTool counts those errors during every session. If a mod gets noisy, a yellow ! shows up next to the profile; click it to see which mods are noisy and how many errors each one threw.

Your dedicated server

Start, stop and restart it, watch the live console and type commands with hints — start typing / and eViSTool suggests the server's commands, including the ones added by mods, and Tab completes them.

The server keeps running when you close the window, and if it crashes it comes back up on its own.

Backups run on a schedule, old ones get cleaned up, and restoring one is a single click — together with the data some mods keep next to the world, like XLeveling's skill progress. Backups can go to any folder you like, a NAS share included; if it's unreachable, the backup stays on the server and moves over next time. Scheduled restarts warn players in chat beforehand and take a fresh backup right before restarting, just in case, and can install mod updates while the server is down.

The Players tab shows everyone who has joined: change roles, manage the whitelist, ban with a duration and reason, kick, or let a player change class and appearance once — they get a chat message telling them to type .charsel.

Notifications tell you when something happens, even with the window closed: the server crashed (and which mod is to blame), a backup failed, mod updates are out, the disk is running low, the server can't keep up, a restart is coming, someone joined. They go to Telegram, Discord, ntfy push on your phone, or any webhook — you pick which events go where. The game chat can go to a Discord channel too, each message under the player's name. Announcements post your rules or Discord link to the chat on a schedule.

Turn on Statistics and you'll see charts of who was online and how hard the server worked (memory and CPU), how long each player has played, and when it crashed — for the last day, week or 30 days. It's off by default and stays on the server's computer.

There's also a proper editor for serverconfig.json: world settings, roles and privileges with checkboxes instead of hand-editing JSON.

Your server on another PC

If the server lives on a different computer (a spare PC, a VM, a rented box), turn on remote access there and you'll get a connection code. Paste it into eViSTool on your own PC, and you can manage that server just like a local one: console, config, backups, schedule, players, statistics, announcements, notifications, and its mods (modpacks too). If that PC runs an older eViSTool, Update there brings it up to your version in one click. Notifications come from that computer, so they reach you even when your own PC is off. The connection is encrypted, and there's nothing to set up beyond the code.

Disk cleanup

The game piles up gigabytes over time: every mod version it ever unpacked, mods from servers you no longer join, maps of old worlds. Disk cleanup shows all of it with sizes and dates, marks what is safe to remove, and moves your pick to the Recycle Bin.

Getting started

  1. Download the zip below (or from GitHub), unzip it anywhere and run eViSTool.exe.
  2. It finds the game and your mods by itself.

You'll need Windows 10 or 11 and the .NET 10 Desktop Runtime. The game uses the same runtime, so if you play Vintage Story you already have it.

The app isn't code-signed yet, so Windows may show "Windows protected your PC" the first time. Click More info → Run anyway. The source code is open if you'd like to look inside.

eViSTool updates itself from GitHub and doesn't collect anything about you. It only talks to GitHub (updates), the ModDB (catalog and downloads), your own server if you turn on remote access, and the notification channels you set up yourself.

По-русски

Я играю в Vintage Story с кучей модов и держу небольшой сервер для друзей. Надоело проверять обновления каждого мода руками, таскать zip-файлы туда-сюда и лезть на сервер ради перезапуска, поэтому я сделал eViSTool. Это одно окно, где можно обновлять моды, ставить новые с модбазы и присматривать за своим выделенным сервером.

Программа бесплатная, с открытым кодом и портативная: распаковал в любую папку и запустил. Интерфейс полностью на русском.

  • Моды: одна кнопка проверяет обновления, можно обновить всё разом, а если что-то сломалось — откатиться на прежнюю версию. Программа заранее подскажет про нехватку зависимостей (чинится одной кнопкой), дубликаты и версии не для твоей игры. Своим набором можно поделиться модпаком.
  • Каталог модбазы прямо в программе: поиск, фильтры, скриншоты, установка в один клик.
  • Настройки модов без ручной правки JSON: форма с переключателями и полями, проверка значений, «Вернуть предыдущую версию» и «Сбросить к стандартным». Работает и для сервера на другом компьютере.
  • Копии миров: перед изменением модов программа копирует одиночные миры, в которые играли, — испортило обновление мир, вернул копию одной кнопкой.
  • Уборка диска: распакованные версии модов, моды с серверов, карты старых миров — с размерами и датами; выбранное уходит в корзину.
  • Профили: несколько сборок игры рядом, у каждой свои моды, настройки и миры. Кнопка «Играть» запускает нужную и видит, что игра уже запущена. Мод, нужный и серверу, и клиенту, можно сразу поставить в несколько профилей, и каждому подберётся версия под его игру. Стрелка у «Играть» запускает игру сразу на сервере: свои серверы, избранное игры или любой из общего списка с поиском и фильтрами.
  • Вылеты: вылетела игра, мир выкинул в главное меню или упал сервер, даже на другом компьютере, — программа подскажет, какой мод скорее всего виноват. Его можно сразу выключить или скопировать отчёт для автора. Моды, которые тихо сыплют ошибками (от них пухнет лог и бывают фризы), отмечаются жёлтой «!» у профиля.
  • Сервер: консоль с подсказками команд, копии мира по расписанию (вместе с данными модов, например прогрессом XLeveling), перезапуски с предупреждением игроков в чате и обновлением модов, удобный редактор конфига. Вкладка «Игроки»: роли, белый список, баны, «выгнать» и разрешение сменить класс и облик. Копии можно складывать в любую папку, в том числе на сетевой диск. Оповещения в Telegram, Discord, ntfy или вебхук: упал, копия не получилась, вышли обновления модов, мало места на диске, сервер не успевает, скоро перезапуск, кто зашёл. Чат игры можно пересылать в канал Discord, каждое сообщение под ником игрока. Объявления в чат по расписанию.
  • Статистика сервера (включается по желанию): графики онлайна, памяти и процессора, сколько наиграл каждый игрок и когда были вылеты, за сутки, неделю или 30 дней.
  • Сервер на другом компьютере: включаешь там удалённый доступ, вставляешь код у себя и управляешь им как своим. Соединение зашифровано. Если там стоит старая версия eViSTool, кнопка «Обновить там» обновит её до твоей.

Скачай zip, распакуй и запусти eViSTool.exe. Подробная инструкция — в README на русском.
