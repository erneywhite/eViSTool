Это версия для Linux. Программа для Windows и полное описание — на странице eViSTool — Windows.

Lots of dedicated Vintage Story servers run on Linux, and now eViSTool runs there too. You put it next to your server, and it looks after the server around the clock as a systemd service. You control it from eViSTool on your Windows PC with a connection code, the same way as any remote server.

There's no window on Linux yet, only the agent and a few commands. A full app for Linux players is planned.

What it does on the server

  • Starts the server with the machine and brings it back after a crash, telling you which mod is most likely to blame.
  • Scheduled world backups with rotation, into any folder, a mounted network share included. Restore with one click.
  • Scheduled restarts: warns players in chat, takes a fresh backup and can install mod updates while the server is down.
  • Notifications to Telegram, Discord, ntfy or any webhook: the server crashed, a backup failed, mod updates are out, the disk is running low, someone joined. The game chat can go to a Discord channel.
  • Chat announcements on a schedule and statistics: who was online, memory and CPU, time played.

From your Windows PC you get everything the Windows app has for a server: the live console with command hints, the config editor, players and whitelist, mods (from the catalog, zips, modpacks), mod settings as a form, and Update on the server, which updates the agent on Linux to your version in one click.

Getting started

If your server is installed the official way, with server.sh, unpack the archive below into its own folder (not into the game folder: the game is updated with rm -rf *) and run:

sudo mkdir -p /home/vintagestory/evistool
sudo tar -xzf eViSTool-<version>-linux-x64.tar.gz -C /home/vintagestory/evistool
sudo chown -R vintagestory:vintagestory /home/vintagestory/evistool
cd /home/vintagestory/evistool
sudo -u vintagestory ./eViSTool.Agent setup
sudo -u vintagestory ./eViSTool.Agent remote enable --host <address of this machine>
sudo -u vintagestory ./eViSTool.Agent remote code
sudo ./eViSTool.Agent service install

Then paste the code into eViSTool on Windows: Settings → + Server → Server on another computer? → Connect by code…

You'll need Linux x64 with systemd (tested on Ubuntu Server 24.04) and .NET 10 for the game server itself. The agent doesn't need .NET, it ships with its own runtime. The step-by-step guide, with ports, day-to-day commands, logs and uninstalling, is on GitHub.

По-русски

Выделенные серверы Vintage Story часто живут на Linux, и теперь eViSTool работает и там. Ставишь его рядом с сервером, и он круглые сутки присматривает за ним как служба systemd. Управляешь им из eViSTool на своём ПК с Windows по коду подключения, как любым удалённым сервером.

Окна на Linux пока нет, только агент и несколько команд. Полноценную программу для тех, кто играет на Linux, сделаю позже.

  • Запускает сервер вместе с машиной и поднимает после падения, а в оповещении пишет, какой мод скорее всего виноват.
  • Копии мира по расписанию с удалением старых, в любую папку, в том числе подключённую сетевую. Восстановление одной кнопкой.
  • Перезапуски по расписанию: предупреждение игрокам в чате, свежая копия и обновление модов, пока сервер стоит.
  • Оповещения в Telegram, Discord, ntfy или вебхук: упал, копия не получилась, вышли обновления модов, мало места, кто зашёл. Чат игры можно пересылать в Discord.
  • Объявления в чат по расписанию и статистика: онлайн, память и процессор, кто сколько наиграл.

С Windows доступно всё, что есть для сервера в программе: консоль с подсказками, редактор конфига, игроки и белый список, моды (из каталога, zip, модпаки), настройки модов формой и кнопка «Обновить на сервере», которая обновит агент на Linux до твоей версии.

Установка — командами выше, если сервер поставлен через server.sh. Подробная инструкция — на GitHub по-русски.
