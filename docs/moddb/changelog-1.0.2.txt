eViSTool 1.0.2: the catalog sees mods that changed their modid.

Fixes
- When a mod's author changes its modid in a new version, the Mod catalog showed the installed mod as not installed and kept offering "Install". Clicking it only reinstalled the same file and the window blinked. Now the catalog recognises a mod by any of its modids: in the list, in the installed/not installed filter and in the card.

Update from About.

eViSTool 1.0.2: каталог видит моды, у которых сменился modid.

Исправления
- Если автор мода сменил modid в новой версии, «Каталог модов» показывал установленный мод как не установленный и предлагал «Установить». Нажатие только ставило тот же файл заново, и окно моргало. Теперь каталог узнаёт мод по любому из его modid: в списке, в фильтре «установленные / не установленные» и в карточке.

Обнови из «О программе».
