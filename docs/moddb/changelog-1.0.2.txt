eViSTool 1.0.2: the catalog sees mods that changed their modid.

Fixes
- GiMap 3.0.0 and other mods whose author changed the modid were installed, but the Mod catalog still showed them as not installed and kept offering "Install". Clicking it only reinstalled the same file and the window blinked. Now the catalog recognises the mod by any of its modids: in the list, in the installed/not installed filter and in the card.

eViSTool 1.0.2: каталог видит моды, у которых сменился modid.

Исправления
- GiMap 3.0.0 и другие моды, у которых автор сменил modid, ставились, но «Каталог модов» по-прежнему показывал их как не установленные и предлагал «Установить». Нажатие только ставило тот же файл заново, и окно моргало. Теперь каталог узнаёт мод по любому из его modid: в списке, в фильтре «установленные / не установленные» и в карточке.

Обнови из «О программе».
