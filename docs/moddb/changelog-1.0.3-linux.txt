eViSTool 1.0.3 for Linux: a Windows-only fix.

Fixes
- This release fixes creating new profiles on Windows (an antivirus scanning freshly copied files blocked the final rename). On Linux nothing changes; updating keeps the versions in step with the Windows window and the agent.
